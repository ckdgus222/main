주요 기능
  • 주변 산책 친구: 위치 공개에 동의하고 최근 5분 안에 위치를 보낸 1km 안의 이웃을 지도와 목록으로 표시합니다. 데모 지도는 미리 저장한 위치를 써서 5분 제한이 없습니다.
  • 산책 요청: 이웃과 반려견 정보를 보고 요청하면 받은 사람이 실시간 알림을 받고 수락하거나 거절합니다.
  • 채팅: 수락된 요청의 두 사람만 Socket.IO로 대화하고, 다시 연결되면 최근 50개 메시지를 다시 불러옵니다.
  • 산책 일기: 반려견별로 사진(최대 5장)과 글을 남기는 기록입니다. 일반 계정은 나만 볼 수 있고, 데모 계정은 공용입니다.
  • 게시판: 이웃과 글·댓글을 공유합니다.
신경 쓴 점
  • 동시성: 같은 두 사람의 대기 중인 산책 요청을 DB 부분 유니크 인덱스로 하나만 허용하고, 반려견 삭제·사진 교체는 행 잠금으로 순서를 보장합니다.
  • 개인정보: 위치를 약 200m 단위로 흐려 저장하고, 사진의 촬영 위치 메타데이터를 제거합니다. 일기 사진은 인증된 API로만 제공합니다.
  • 인증: 접속 토큰은 메모리에만, 리프레시 토큰은 HttpOnly·SameSite=Strict 쿠키에 담고 DB에는 해시만 저장합니다. IP별 로그인 시도를 제한합니다.
  • 집에 있는 Ubuntu 서버에 nginx를 직접 설치해 옆집 강아지와 Client Review를 도메인별로 연결했습니다. 웹·API·DB는 Docker Compose로 운영하고 HTTPS 인증서는 자동 갱신합니다. 부팅 때 USB 백업과 데모 데이터 초기화를 실행합니다.

주요 기능
  • 기능 흐름 따라가기: 화면에서 시작해 요청, 서버, DB까지 기능 하나를 단계별로 따라갑니다. 단계마다 근거가 된 코드 줄을 함께 보여 주고, 코드에서 찾지 못한 단계는 건너뜁니다.
  • 프로젝트 지도: 어떤 화면이 어떤 서버 기능을 부르는지, 어떤 파일이 어떤 파일을 가져다 쓰는지 그림으로 봅니다.
  • 코드 읽기: 함수가 어디서 불리고 무엇을 부르는지, 값이 어디서 와서 어디로 가는지 따라갑니다.
  • 검토 도우미: 사용되지 않는 파일 후보와 긴 함수를 짚어 줍니다. macOS에서는 커밋해 둔 코드와 지금 코드를 나란히 비교할 수 있습니다.
  • AI 설명: 모르는 함수를 AI에게 물어보거나, 기획 문서와 실제 코드가 맞는지 비교해 볼 수 있습니다.
신경 쓴 점
  • 읽기 전용: 열어 본 프로젝트의 파일을 고치지 않고, 그 안의 코드나 스크립트도 실행하지 않습니다.
  • 근거 표시: 흐름의 각 단계에 근거가 된 코드 줄을 붙이고, 확실하지 않은 연결은 ‘추정’이라고 따로 표시합니다.
  • AI 설명은 선택 사항입니다. 코드 탐색과 지도는 AI 없이 동작하고, AI 설명을 요청하면 보낼 내용과 대상을 보여 준 뒤 동의를 받습니다.

구현한 검수 과정
  • 개발자가 PC·모바일 화면 사진을 버전별로 올리면, 고객은 사진에서 고칠 자리를 눌러 수정 요청을 남깁니다.
  • 고친 화면을 이전 버전과 나란히 비교하고, 담당자가 승인하면 해당 버전의 검수 확인서를 볼 수 있습니다.
  • 새 버전이 올라오거나 승인이 끝나면 참여자에게 이메일로 알리는 기능을 구현했습니다.
구현 세부 사항
  • Ubuntu 홈서버의 공용 nginx가 화면을 제공하고 API 요청을 전달합니다. API와 PostgreSQL은 Docker Compose로 운영하며 HTTPS 인증서는 자동 갱신합니다.
  • 이메일로 받은 6자리 코드로 로그인합니다. 코드는 10분 뒤 만료되고, 한 코드로 시도할 수 있는 횟수는 5회입니다.
  • 동시 요청: 같은 코드가 동시에 두 번 들어와도 세션은 하나만 생깁니다. 조건을 건 UPDATE 한 문장으로 막았습니다.
  • 보안: 쿠키는 SameSite=Lax로 두고, 쓰기 요청마다 Origin을 확인합니다. 세션 토큰은 DB에 해시로만 저장합니다.
  • 디자인: 시안 색을 그대로 쓰면 흐린 글자와 입력칸 테두리가 잘 안 보여서, 대비 기준을 넘는 색으로 바꿔 적용했습니다.
