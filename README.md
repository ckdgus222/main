# 최창현 포트폴리오

"Night Glass" 디자인과 업무 개념도를 적용한 정적 HTML 포트폴리오입니다.
깊은 남색 바탕에 연보라 빛이 번지고, 경력은 반투명 유리 카드와 세로 타임라인으로 보여줍니다.

## 실행

프로젝트 루트에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

<http://127.0.0.1:8765/>에서 확인할 수 있습니다. 별도 빌드나 패키지 설치는 필요하지 않습니다.

## 디자인 시스템

[디자인 시스템 가이드](http://127.0.0.1:8765/design-system.html)에서 현재 프로젝트의 색상, 타이포그래피, 간격, 반응형 규칙과 실제 컴포넌트를 확인합니다.

- `assets/css/tokens.css`가 공통 값의 기준입니다. 홈페이지와 가이드가 같은 파일을 사용합니다.
- 스타일시트는 `font.css` → `tokens.css` → `experience-visuals.css` → `portfolio.css` 순서로 연결합니다. 카드 안 개념도의 테두리·위치는 `portfolio.css`가 정하므로 개념도 스타일 다음에 둡니다.
- 토큰에는 사용 목적을 나타내는 이름을 사용합니다(`--text-soft`, `--glass-border`, `--accent-line`). 강조색의 투명도 변형은 `color-mix()`로 기본색에서 만들므로 `--accent`만 바꾸면 틴트·선·빛 번짐이 함께 바뀝니다.
- 간격은 4px 단위 하나(`--space-1` 4px ~ `--space-32` 128px), 모서리는 `--radius-card` / `--radius-inner` / `--radius-pill` 세 가지입니다.
- 유리 표면(`.glass`)에는 남색 틴트(`--glass-tint`)를 깔아 빛 번짐 위에서도 글자 대비 4.5:1 이상을 유지합니다. 대비는 실제 렌더링 화면에서 측정합니다.
- `design-system.html`과 `assets/css/design-system.css`는 가이드의 구성과 배치를 담당합니다.
- `assets/js/design-system.js`는 현재 화면의 토큰 값 표시, 예제 복사, 모션 다시 보기를 담당합니다. JavaScript 없이도 가이드 본문과 컴포넌트 예시는 읽을 수 있습니다.
- 홈페이지 동작도 같은 모션 토큰(`--dur-reveal`, `--reveal-distance`, `--stagger`, `--ease-out`)을 사용합니다. JavaScript에서 읽는 시간은 `ms`, 거리는 `px` 단위로 작성합니다. 형식이 잘못되면 등장 효과를 생략하고 본문을 바로 표시합니다.
- 미디어 쿼리의 경계(1199/1023/767/359px)는 CSS 변수로 바꿀 수 없으므로 `tokens.css`, `portfolio.css`, `design-system.css`와 가이드 설명을 함께 관리합니다. 경력 카드는 카드 너비 760px(본문·개념도 2열)와 480px(기술 분야 이름을 태그 위로)를 기준으로 하는 컨테이너 쿼리를 사용합니다.
- 업무 개념도의 고유 좌표·그라데이션·장식 색상은 `experience-visuals.css`에 둡니다. 공통 선(`--line`)과 개념도 잉크·강조색(`--color-illustration-*`)만 토큰을 공유합니다.
- 공유 CSS·JS를 수정하면 사용하는 두 HTML의 `?v=` 값을 해당 파일의 SHA-256 앞 10자리로 함께 갱신합니다.

## 수정할 파일

- `index.html`: 소개·요약 카드, 실무 경험 타임라인 4건, 기술 스택, 메인 프로젝트, 개념도, 연락처, 하단 탭바, 검색·공유 메타
- `assets/css/tokens.css`: 색상, 글꼴, 간격, 모서리, 그림자, 레이아웃과 모션의 공통 디자인 토큰
- `assets/css/portfolio.css`: 토큰을 사용하는 페이지 배치, 컴포넌트와 반응형 스타일
- `assets/css/experience-visuals.css`: 업무 개념도 스타일
- `assets/js/portfolio.js`: 현재 메뉴·경력 레일 표시, 소개·섹션 등장 효과, 타임라인 진행선, 유리 반사광
- `assets/css/font.css`: Pretendard 글꼴

기본 링크와 상세 펼치기는 JavaScript 없이도 동작합니다.
소개 문구는 단어 단위로 나타나고, 섹션과 카드는 화면 밖으로 완전히 나갔다가 다시 들어올 때마다 부드럽게 나타납니다. 위·아래 스크롤 모두 동일하게 적용합니다.
타임라인 선은 스크롤 위치까지 채워지고, 지나간 사례의 점이 켜집니다. 데스크톱에서는 카드에 가벼운 호버 효과와 포인터를 따라가는 반사광을 적용합니다.
별도 애니메이션 라이브러리 없이 브라우저 기본 기능을 사용합니다. 동작 줄이기 설정에서는 등장·이동 효과를 끄고 타임라인을 처음부터 모두 표시하며, JavaScript가 없어도 본문은 표시됩니다.
개념도는 실제 서비스 스크린샷이 아닌 담당 기능을 설명하는 일러스트입니다.

페이지와 본문 메뉴는 소개 → 실무 경험(`#work`) → 기술 스택(`#skills`) → 메인 프로젝트(`#portfolio`) → 연락 순서입니다.
767px 이하에서는 헤더 메뉴 대신 화면 아래에 고정된 탭바로 이동합니다.
회사 경력과 외주 개발 경험을 먼저 보여준 뒤 사용하는 기술과 개인 프로젝트를 소개합니다.

실무 경험(`#work`)은 회사 경력 1건과 외주 개발 3건을 타임라인의 두 묶음으로 나눠 보여줍니다.
위쪽 레일에서 각 사례로 바로 이동할 수 있고, 사례마다 기간·구분·고객사·역할과 세부 업무, 개념도를 표시합니다.

기술 스택(`#skills`)은 프론트엔드, 백엔드·자동화, 데이터·스토리지, 빌드·배포, 스타일링, 상태 관리의 여섯 분야로 구성합니다.
각 분야에서 사용하는 기술 이름을 태그 목록으로 표시합니다.
작업 내용이나 회사·외주·개인 구분은 기술 카드에 넣지 않습니다.

메인 프로젝트(`#portfolio`)에는 개발 중인 강아지 산책 프로젝트를 배치합니다.
메인 프로젝트는 개발 중 표시·서비스 소개·주요 기술 스택·콘셉트 이미지로 구성합니다.
구현 범위나 상세 기술 설명은 표시하지 않습니다.
`assets/images/dog-walk-concept.png`는 AI로 만든 콘셉트 이미지로 실제 서비스 화면이 아닙니다.
회사 경력과 외주 3건은 실무 경험(`#work`)에 별도로 유지합니다.

`previews/`에는 비교용 시안 A/B/C와 현재 디자인의 시안 D를 보관합니다(git에 포함하지 않는 로컬 폴더). 시안 파일은 홈페이지에 영향을 주지 않습니다.
이후 홈페이지 변경은 위의 루트 파일과 `assets/`에 직접 적용합니다.

`index.html`과 `design-system.html`의 페이지 CSS·JavaScript 링크에는 캐시 갱신용 `?v=` 값이 있습니다.
해당 파일을 수정하면 이 값도 갱신해, 기존 탭에 이전 스타일이나 동작이 남지 않도록 합니다.
