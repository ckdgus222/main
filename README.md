# 최창현 포트폴리오

선택한 C 시안과 업무 개념도를 적용한 정적 HTML 포트폴리오입니다.

## 실행

프로젝트 루트에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

<http://127.0.0.1:8765/>에서 확인할 수 있습니다. 별도 빌드나 패키지 설치는 필요하지 않습니다.

## 수정할 파일

- `index.html`: 소개, 메인 프로젝트, 실무 경험 4건, 개념도, 연락처, 검색·공유 메타
- `assets/css/portfolio.css`: 페이지 배치와 반응형 스타일
- `assets/css/experience-visuals.css`: 업무 개념도 스타일
- `assets/js/portfolio.js`: 스크롤 위치에 따른 메뉴 표시
- `assets/css/font.css`: Pretendard 글꼴

기본 링크와 상세 펼치기는 JavaScript 없이도 동작합니다.
개념도는 실제 서비스 스크린샷이 아닌 담당 기능을 설명하는 일러스트입니다.

메인 프로젝트(`#portfolio`)에는 개발 중인 강아지 산책 프로젝트를 배치합니다.
메인 프로젝트는 개발 중 표시·서비스 소개·주요 기술 스택·콘셉트 이미지로 구성합니다.
구현 범위나 상세 기술 설명은 표시하지 않습니다.
`assets/images/dog-walk-concept.png`는 AI로 만든 콘셉트 이미지로 실제 서비스 화면이 아닙니다.
회사 경력과 외주 3건은 실무 경험(`#work`)에 별도로 유지합니다.

`previews/`에는 비교용 A/B/C를 보관합니다. 비교 화면 생성 명령은 홈페이지에 영향을 주지 않습니다.
이후 홈페이지 변경은 위의 루트 파일과 `assets/`에 직접 적용합니다.

`index.html`의 페이지 CSS 링크에는 캐시 갱신용 `?v=` 값이 있습니다.
해당 CSS를 수정하면 이 값도 갱신해, 기존 탭에 이전 스타일이 남지 않도록 합니다.
