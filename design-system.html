01 / PRINCIPLES

원칙

내용의 우선순위가 시각적 위계를 결정합니다. 빛과 유리는 분위기를 만들 뿐, 읽기를 방해하지 않습니다.

01

경력 우선

회사 경력과 외주 개발을 타임라인의 두 묶음으로 나누고, 기간·소속·고객사·역할을 함께 표시합니다.

02

텍스트 우선

카드에서 제목과 핵심 업무를 먼저 읽고, 개념도는 옆(넓은 카드)이나 아래(좁은 카드)에 둡니다. 개념도는 실제 화면이 아님을 표시합니다.

03

빛은 배경에, 글자는 선명하게

빛 번짐과 유리 표면 위에서도 모든 글자는 실제 렌더링 기준 4.5:1 이상의 대비를 유지합니다.

04

절제된 동작

작은 이동과 색으로 반응을 알립니다. 동작 줄이기 설정이나 JavaScript가 없어도 같은 내용을 제공합니다.

MOTION SAMPLE

텍스트가 먼저, 움직임은 가볍게.

JS가 활성화되면 데모를 다시 재생할 수 있습니다. 시간·거리·가속 곡선은 root 토큰을 따르며 홈페이지의 portfolio.js도 같은 토큰을 읽습니다. 가이드에서는 portfolio.js를 실행하지 않습니다.

  • 본문은 JS 없이 읽고, details/summary로 세부 내용을 펼칩니다.
  • 소개는 단어 단위로 나타나고, 섹션과 카드는 화면 밖으로 완전히 나갔다가 다시 들어오면 다시 나타납니다. 포커스가 들어온 요소와 인쇄 시에는 즉시 표시합니다.
  • 타임라인 선은 화면 45% 지점까지 채워지고, 그 지점을 지난 사례의 점이 켜집니다.
  • prefers-reduced-motion: reduce에서는 애니메이션·전환·부드러운 스크롤을 끄고, 타임라인을 처음부터 모두 표시합니다.
  • 포커스는 2px 테두리·4px 바깥 여백. 조작 영역은 최소 44px, 상세 펼침은 52px입니다.
  • 호버 이동·반사광은 정밀 포인터에서만 적용하고, 터치에서 필요한 정보를 숨기지 않습니다.
  • 글자 대비는 실제 렌더링 픽셀로 측정합니다. 유리에는 --glass-tint를 깔아 빛 번짐 위에서도 4.5:1 이상을 유지합니다.
  • 의미 있는 개념도에는 대체 설명을, 장식에는 aria-hidden을 적용합니다. 강제 색상 모드에서는 테두리를 시스템 색으로 표시합니다.

UI 적용 체크리스트

  • 새 값을 선언하기 전에 기존 토큰과 컴포넌트를 먼저 확인합니다.
  • 회사 경력·외주 구분, 기간·고객사·역할, 실제 기술 문구를 확인합니다.
  • 320px와 각 반응형 경계 전후에서 긴 문구·칩·코드의 넘침과 개념도 글자 경계를 확인합니다.
  • Tab 순서, Enter·Space 펼침, 링크 목적지, 200% 확대를 확인합니다.
  • JS 비활성화·동작 줄이기·폰트 로딩 실패에서 모든 내용이 보이는지 확인합니다.
  • 빛 번짐 위 작은 글자를 포함해 실제 화면에서 대비를 측정합니다.
  • 변경 시 홈페이지와 가이드를 함께 검토하고 CSS·JS 버전 값을 갱신합니다.
